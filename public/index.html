One inbox for the fediverse

This server relays public ActivityPub traffic between subscribed instances. Traditional relays register through /inbox; server actors can instead follow the relay actor at /actor. Every delivery is signed with the relay key using legacy Fediverse HTTP signatures or RFC 9421.

How to subscribe

  1. Mastodon / Misskey: add https://relay.example.org/inbox as a relay in your instance administration.
  2. Pleroma / Akkoma / Friendica: follow @relay@relay.example.org from your server actor.
  3. Unsubscribe: remove the relay or send Undo Follow.

About personal accounts

A relay connects instances, never personal accounts. Following the relay actor from a regular account is rejected on purpose, because the relay would otherwise send every public activity to one person's home timeline.

Only public activities are distributed, and the relay never exposes subscriber identities, inbox URLs or relayed activity history. Account deletion notices are acknowledged without being relayed.
