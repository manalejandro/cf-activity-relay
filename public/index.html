One inbox for the fediverse

This server relays public ActivityPub traffic between subscribed instances. Traditional relays register through /inbox; server actors that prefer following can follow the relay actor at /actor. Every delivery is signed with the relay key using legacy Fediverse HTTP signatures or RFC 9421.

Connected instances – receiving or publishing
Receiving instances – subscribers and followers
Publishers – observed senders
Registration – public posts only

How to subscribe

  • Mastodon / Misskey: add https://relay.manalejandro.com/inbox as a relay in your instance administration.
  • Pleroma / Akkoma / Friendica: follow @relay@relay.manalejandro.com from your server actor.
  • Unsubscribe: remove the relay or send Undo Follow.

Relays connect instances, not personal accounts: a follow from a regular account is rejected by design, because the relay would otherwise send every public activity to one person's home timeline.

Only public activities are distributed. The relay never exposes subscriber identities, inbox URLs or relayed activity history.
