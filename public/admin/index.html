Sign in

Enter the relay admin token. It is kept in this browser tab only and sent as a bearer token to the relay API.

The token is the value of the ADMIN_TOKEN secret.

Person-only publishing

Pending requests

Receivers

Instances that receive relay traffic. Removing one is equivalent to an accepted Undo Follow.

Follower-style receivers

Server actors that follow the relay actor and receive the reciprocal follow.

Add a receiver

Resolves the actor's shared inbox and registers it as a traditional subscriber, without needing a relay UI on the remote server.

Examples: https://mastodon.example/actor, https://instance.example/users/guardian.

Domain policy

Blocked domains are rejected with 401. Limited domains are silently skipped and never receive a reciprocal follow.
